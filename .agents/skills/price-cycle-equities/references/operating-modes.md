# 工作模式

## 解释

输入可以只是一个概念。用通俗语言先回答“它是什么、为什么、如何识别、哪里会失效”，
并区分原规则与工程假设。没有分析具体证券时不要求市场数据。

## 分析

最小输入：

- 标的及市场；
- as_of 日期和周期；
- 带日期的行情或可检查的图表；
- 数据来源和复权口径。

流程：数据审计 → 市场背景 → CAN SLIM 证据 → Cycle 候选阶段 → 风险与未知项。
数据不足时输出最小补充清单，不编造精确阶段。

## 计划

先完成分析，再给出条件式方案：

- 触发条件；
- 结构失效条件；
- 计划入场与初始止损的来源；
- 每股风险和仓位公式；
- 市场可交易限制；
- 不触发或证据冲突时的行动。

不要把方案写成已下达订单。

## 扫描

所有证券使用同一 as_of、同一数据版本和同一参数集。先做可交易性和数据质量过滤，
再输出排名、证据、未知项和淘汰原因。排名只用于研究优先级。

## 复盘

只使用当时可见数据。分别检查：

1. 选股背景；
2. 阶段和枢轴；
3. 初始风险；
4. 执行可达性；
5. 持仓管理；
6. 结果与过程是否混淆。

盈利交易也可能违反流程，亏损交易也可能严格遵守流程。

## 研究

先写假设和反证条件，再决定参数。必须记录策略规范版本、参数哈希、市场规则版本、
数据快照和执行模型。明确区分训练期、验证期和样本外期，禁止未来函数。
