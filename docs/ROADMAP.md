# 零基础共建路线

目标版本 v0.1.0：支持 A 股与美股日线/周线研究，输出 Cycle 候选阶段、
CAN SLIM 证据、数据质量、失效条件和风险提示；不接实盘、不自动下单。

## 里程碑

- [x] **策略事实规范**：每条规则有来源类别，A/美股适配不冒充原规则。
- [x] **可识别的 Skill 骨架**：目录、触发说明和统一报告格式通过官方校验。
- [x] **确定性分析核心**：读取固定 CSV 数据，计算 EMA、SMA、ATR、相对强度、事件账本与候选阶段。
- [x] **双市场规则层**：按有效日期解析 A 股与美股核心约束；缺身份、动态状态或过期核验时 fail closed。
- [x] **样例与测试**：A 股 Wedge Pop 与美股 Wedge Drop 黄金样例；包含无未来数据与价格缩放测试。
- [x] **本地可用版**：零基础说明、输入模板、确定性 CLI 和一条命令的验证流程。
- [ ] **GitHub 发布**：检查隐私、版权和密钥后，创建仓库、推送并打 v0.1.0 标签。

## 每一步如何验收

每个里程碑都只回答三个问题：

1. 这一步新增了什么可见成果？
2. 哪些自动检查已经通过？
3. 下一步用户只需确认哪一个选择？

GitHub 阶段才需要用户登录；不要在聊天中发送密码、验证码或访问令牌。
