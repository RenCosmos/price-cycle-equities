# 零基础共建路线

当前开发线 v0.2.0：在 v0.1.x 的 A/美股日线确定性研究上增加可切换、多源容错
的数据获取层。周线确认仍未进入确定性分析器；不接实盘、不自动下单。

## 里程碑

- [x] **策略事实规范**：每条规则有来源类别，A/美股适配不冒充原规则。
- [x] **可识别的 Skill 骨架**：目录、触发说明和统一报告格式通过官方校验。
- [x] **确定性分析核心**：读取固定 CSV 数据，计算 EMA、SMA、ATR、相对强度、事件账本与候选阶段。
- [x] **双市场规则层**：按有效日期解析 A 股与美股核心约束；缺身份、动态状态或过期核验时 fail closed。
- [x] **样例与测试**：A 股 Wedge Pop 与美股 Wedge Drop 黄金样例；包含无未来数据与价格缩放测试。
- [x] **本地可用版**：零基础说明、输入模板、确定性 CLI 和一条命令的验证流程。
- [x] **GitHub 发布**：隐私、版权和密钥检查通过；已推送 `main` 并发布 `v0.1.0` 标签。
- [x] **v0.1.1 语义纠偏**：区分六个来源阶段家族与八个方向化候选，修正失败
  Crossback、窗口中途开始的 Wedge Drop，以及无支持候选时的 UNKNOWN 摘要。
- [x] **v0.2.0-alpha.1 数据骨架**：统一 provider 契约、注册表、顺序回退、
  来源工件、点时校验和成交量质量门；CSV 作为第一个 provider。
- [ ] **v0.2.0-alpha.2 首个远程源**：在用户显式配置凭证后接入一个大陆优先源，
  同时用境外独立源做等价性与回退验收。
- [ ] **v0.2.0-beta 多源验收**：增加美股 SEC 财务与境外行情备份，完成限频、
  缓存、修订、公司行动和跨源偏差测试。

## 每一步如何验收

每个里程碑都只回答三个问题：

1. 这一步新增了什么可见成果？
2. 哪些自动检查已经通过？
3. 下一步用户只需确认哪一个选择？

GitHub 阶段才需要用户登录；不要在聊天中发送密码、验证码或访问令牌。
